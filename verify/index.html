What this does

Every Airlock Monitor audit run is signed with an Ed25519 key. This page lets you independently verify that a report is genuine and unmodified — the signature check runs entirely in your browser using the Web Crypto API.

How verification works

  1. Canonical form. The {header, result} payload is re-serialized with recursively sorted keys — the same deterministic encoding the signer uses.
  2. SHA-256 integrity. The SHA-256 hash of the canonical string is computed and compared against the one in the attestation.
  3. Ed25519 signature. The Ed25519 signature is verified against the canonical bytes using the signer's public key (SPKI DER format).
  4. Trusted key check. The public key in the attestation is compared against ShipSealed's known production signing key.
AIRLOCK MONITOR

Every run, signed and verifiable

Airlock Monitor signs every audit run with Ed25519. The attestation includes the full audit result, a SHA-256 integrity hash, and a cryptographic signature — so you can prove to auditors and customers that the security check actually ran.
